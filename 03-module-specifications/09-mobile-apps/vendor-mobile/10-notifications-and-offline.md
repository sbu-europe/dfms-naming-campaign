# Vendor Mobile — Notifications & Offline

## Push notifications (critical)

- New bid opportunities
- Bid awards
- TO assignments
- Trip status updates

**Implementation:**
- **Android:** Firebase Cloud Messaging (FCM)
- **iOS:** Apple Push Notification Service (APNs)

## Offline capability

**Limited offline (read-only):**
- View cached assigned TOs and active trips
- View completed trip history

**Online required:**
- Bid submission
- Post-award driver/vehicle detail submission
- Profile updates
