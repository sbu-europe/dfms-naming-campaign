# Vendor Mobile Application — Overview, Onboarding, and Access

## Overview

The Vendor Mobile Application is the **vendor-facing mobile interface** that enables third-party transport vendors to participate in DFMS operations. It provides access to bidding opportunities, assigned transport orders, active trip tracking, and profile management—enabling vendors to manage their transport business on-the-go.

The app complements the desktop-based Vendor Portal, offering mobile convenience for time-sensitive actions like bid submission and operational updates.

## Purpose

- **Onboarding Entry:** Self-registration or platform-admin invite → vendor completes profile and submits for verification
- **Tenant Participation:** Browse active tenants, request to join, and operate only within tenants that approve the vendor
- **Bid Management:** View available TOs for bidding, submit competitive bids
- **TO Management:** View assigned TOs (won bids or contractual allocations)
- **Post-Award Actions:** Assign drivers, vehicles, and helpers to awarded TOs
- **Trip Tracking:** Monitor active trip progress and status
- **Trip History:** Review completed trips for invoicing and performance analysis
- **Profile Management:** Update vendor profile (Phase 1 does not include driver/vehicle master lists)
- **Notifications:** Real-time alerts for new bids, TO assignments, trip updates

---

## Onboarding, Verification, and Tenant Membership

### Entry Paths

- **Self-registration:** Vendor signs up and submits required profile + documents for verification.
- **Invite-based onboarding:** Platform admin creates vendor and sends an invite; vendor completes missing details + documents and submits for verification.

### Verification (access requirement)

- Vendor status remains **inactive** until verification is complete.
- Unverified vendors cannot view tenant bids or tenant TO/trip details.

### Tenant join approval (after verification)

- Vendor can view all **active tenants**.
- Vendor can request to join one or more tenants.
- A tenant must approve the join request before the vendor can:
  - View bid opportunities for that tenant
  - View assigned TOs and trips for that tenant
  - Submit bids for that tenant
