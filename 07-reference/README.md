# 07-reference - Reference Materials

> Archive, data dictionaries, reports, and reference documentation

## Overview

This folder contains reference materials, archived documents, and supporting documentation that doesn't fit into the main documentation structure.

## Structure

### `archive/` - Archived Documentation
Older versions of documents, deprecated specs, and historical records.
- Previous documentation versions
- Legacy structure artifacts
- Superseded documents

### `data-reference/` - Data Dictionaries
Data definitions, field specifications, and data reference guides.
- `data-dictionary.md` - Comprehensive data dictionary
- `master-data/` - Master data specifications
- `transactional-data/` - Transactional data specifications

### `reports/` - Project Reports
Verification reports, status updates, and project documentation.
- `VERIFICATION_REPORT.md` - Documentation verification and validation report

## Usage

This folder serves as:
- Historical record of documentation evolution
- Reference for data structures and definitions
- Repository for project reports and status documents
- Archive for deprecated but potentially useful content
