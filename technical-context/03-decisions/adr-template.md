**Deciders**: [List of decision makers]

---

---

## ADR Numbering

- **ADR-001** to **ADR-099**: Core architecture decisions
- **ADR-100** to **ADR-199**: Technology choices
- **ADR-200** to **ADR-299**: Integration decisions
- **ADR-300** to **ADR-399**: Security decisions
- **ADR-400** to **ADR-499**: Performance decisions

---

## Status Values

- **Proposed**: Decision is being considered
- **Accepted**: Decision has been made and is in effect
- **Deprecated**: Decision is no longer valid
- **Superseded**: Decision has been replaced by another ADR

---

## Tags

Common tags:
- `architecture` - Overall architecture decisions
- `technology` - Technology stack choices
- `integration` - Integration patterns
- `security` - Security-related decisions
- `performance` - Performance optimizations
- `scalability` - Scalability considerations
- `data` - Data-related decisions
- `api` - API design decisions
- `events` - Event-driven architecture
