# 03-backlog/sprints — Sprint-wise Backlog (Current Source of Truth)

This is the live, actively maintained DFMS backlog. Each `sprint-N/` folder holds that
sprint's stories, sub-tasks, status, improvements, and post-demo feedback resolution —
everything needed to understand what was planned and what actually shipped.

> **Superseded folder**: `_meta/archive/backlog-stories-pre-sprint2/` (the original flat `US-XXX` pre-Sprint-2
> backlog) has been archived to
> [`_meta/archive/backlog-stories-pre-sprint2/`](../../_meta/archive/backlog-stories-pre-sprint2/README.md).
> Do not use it as a source of truth — use the sprint folder for the relevant module instead.
>
> **Unscheduled Phase 2 stories** live in [`../stories-phase-2/`](../stories-phase-2/README.md), not under a sprint.
