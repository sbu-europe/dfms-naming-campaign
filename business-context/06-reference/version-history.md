## 📝 Update Process

### How to Update Documentation

1. **Minor Updates** (typos, clarifications):
   - Update the document directly
   - Update `updated` date in frontmatter
   - Commit with descriptive message

2. **Substantial Updates** (new sections, major changes):
   - Create new version number (increment MINOR)
   - Update version history (this document)
   - Update all affected cross-references
   - Commit with version tag

3. **Major Restructuring** (folder changes, major additions):
   - Create new version number (increment MAJOR)
   - Update all navigation and indexes
   - Update version history
   - Create migration guide if needed
   - Commit with version tag
